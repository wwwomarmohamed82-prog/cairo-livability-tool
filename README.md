# Cairo Neighborhood Livability Tool

A Python web app that scores any Cairo neighborhood based on the presence of key amenities (hospitals, schools, banks, parking, police stations).

## Built With
- Python
- OSMnx (OpenStreetMap data)
- GeoPandas
- Folium
- Streamlit

## How to Run
pip install osmnx folium streamlit geopandas streamlit-folium
streamlit run app.py
## Features
- Live amenity data from OpenStreetMap
- Weighted livability scoring
- Interactive map with amenity pins
